## The audits

`docs/plans/2026-11-03-compositor-audit.md` holds the audit and bug hunt. It records the Ctrl+F
proof, the thirteen default binds that did nothing at all, the two config warnings that were
silent, the overlay that advertised actions the compositor never applies, the two CI flakes and the
wlroots listener sweep.

The listener sweep is done by hand: six sites attach a listener to a surface that can be destroyed,
and all six pair the commit listener with a destroy listener that drops both. The named-shape path
was the only leak and it is fixed. `Listener.Destroy()` is idempotent, so the toplevel path's
double drop is safe.

Two real CI failures were found and explained:

- `TestAnimateValuePreservesSameTargetAndRetargetsSample` — a timing flake; the test sampled the old
  spring at its own instant while the new spring was created a few microseconds later. Fixed.
- `TestPortalColorPickerReturnsPixelAndCancels` — still open, intermittent; a stale or empty render
  buffer under vkms gives a black pixel. Bead `sysc-2219` covers the overview scroll fixture flake.

## Owner decisions in force

- **The attribution guard is not to be edited or bypassed.** `/home/nomadx/.git-hooks/` holds a
  `commit-msg` and a `pre-push` hook that reject any commit message or author metadata matching
  `cursor`, `claude`, `anthropic`, `chatgpt`, `openai`, `copilot`, `cody`, `tabnine`, `codex`,
  `gemini`, `bard`, `gpt-[0-9]`, `llm`, `ai assistant`, `bot` or `agent`. The word "bot" matches
  inside "both", so commit subjects must say "the two", never "both". Use "pointer image" and
  "pointer surface" for the wlroots pointer API. The hooks only ever read commit messages, never
  file contents, so upstream identifiers in the code are fine.

  and the guard refused every push that included it. Cherry-pick instead. The merge commit was

  force-pushed with `--force-with-lease`.
- **The bar and a fullscreen window**: keep niri parity — the compositor does not change the
  fullscreen geometry and the shell hides its own bar. The compositor reports `is_fullscreen` so
  the shell can do it.

## Working notes

- Build and test: `CGO_CFLAGS_ALLOW=-fno-strict-overflow GOTMPDIR=/home/nomadx/.cache/go-tmp
  TMPDIR=/home/nomadx/.cache/go-tmp timeout 120s env GOMAXPROCS=2 go test -count=1 <pkg>`. The
  `-fno-strict-overflow` comes from `pkg-config wlroots-0.20` and cgo refuses it without the
  allowance. `/tmp` on archPC is a nearly full tmpfs, so both `GOTMPDIR` and `TMPDIR` have to point
  at the cache directory or the linker fails with "disk quota exceeded".
- One package and one named test at a time. Never `go test ./...`, never `-race`. `internal/wlr` and
  `internal/server` are excluded from the local test policy because they need a compositor; CI lane
  2 runs them under vkms.
- `runtime.LockOSThread()` before any wlroots call. Go and cgo only; no `.c` or `.h` in this tree.
- `go generate ./internal/wlr` writes the protocol headers into the gitignored
  `internal/wlr/protocols/`. Run it once in a fresh clone before building.
- The niri reference checkout for the behaviour target is `/home/nomadx/references/niri` at tag
  v26.04. Prefer it over anything fetched from niri's `main` branch.
- The bd database with the sysc issues is `/home/nomadx/sysc-shell/.beads`. Run `bd` from
  `/home/nomadx/sysc-shell`, never from a worktree.
