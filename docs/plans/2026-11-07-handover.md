## 3. What landed on 2026-11-07

- **Slice 5 proven (#94).** Three of the four slice 5 compositor tests failed on first run. Fixes:
  the shadow now follows Niri's geometry (an M8 bug: half the softness, box inside the tile);
  window rules are resolved again on title and app-id changes, as Niri does; two test
  assumptions corrected. Details: the config plan's slice 5b and 5c records.
- **Shell touch (sysc-shell #622).** The owner chose the client-side fix. Niri has no pointer
  emulation and Mango's is opt-in, off by default. The shell binds `wl_touch` and turns the first
  finger into its pointer events. Owner-accepted on archThink: bar taps and panel use; the
  compositor logged 0 dropped touch-downs after the deploy.
- **Wake and idle (#97, `sysc-2254`).** Touch down and motion, swipe begins, and pinch and hold
  begins now reset idle and wake monitors turned off by `PowerOffMonitors`. Releases and gesture
  ends reset idle without waking, per Niri's `should_activate_monitors`. Pointer motion already
  woke them: the bead misread the code, and the owner confirmed with the trackpad.
- **Compositor UI touch (#98, unmerged).** The overview, window switcher, screenshot UI and exit
  dialog take a finger through the pointer path, as Niri's `on_touch_down` routes them. A touch
  down hides the hotkey overlay; the colour picker takes none. Known differences are in the
  touchscreen plan.

## 6. Proving compositor tests

Nested tests need the owner's consent on the desktop. Use the laptop session VM instead: the
owner pre-approved it, and it matches CI's lane 2.

1. `git archive` the tree (or tar `git ls-files` for uncommitted work) and copy it to
   `laptop:vm/sysc-session/`. Boot with `ssh laptop 'cd ~/vm/sysc-session && ./run.sh lane2'`
   and wait until `./vssh true` succeeds.
2. In the VM: extract to `~/<dir>`, run `go generate ./internal/wlr`, make a `~/lane2.sh` copy
   with `sed "s#cd ~/sysc-compositor#cd ~/<dir>#"`, and export
   `CGO_CFLAGS_ALLOW=-fno-strict-overflow` (vet fails without it).
3. For a regression test, run the new test on `main` plus the test file, then on the fix; the
   first should fail.
4. Run `internal/wlr` in two batches: list with `go test -list .`, split the names in half, and
   run each half with `-run "^(a|b|…)$"`. Then run `internal/server`. The four skips in
   `.github/ci/skips.txt` are expected.
5. `./vssh sudo systemctl poweroff` and delete the copied archive afterwards.

cgo is not allowed in `_test.go` files; diagnostics that need C go in a non-test file of a scratch
copy.
