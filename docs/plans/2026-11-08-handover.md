## 5. Proving compositor tests

Nested tests need the owner's consent on the desktop. Use the laptop session VM instead: the
owner pre-approved it, and it matches CI's lane 2. The recipe is the 2026-11-07 handover §6. In
short:

1. `git archive --prefix=<dir>/ HEAD` to `laptop:vm/sysc-session/`, then
   `ssh laptop 'cd ~/vm/sysc-session && ./run.sh lane2'` and wait for `./vssh true`.
2. In the VM: `./vssh "tar xzf - -C ~" < archive`, then `go generate ./internal/wlr`, then make
   `~/lane2-<dir>.sh` from `~/lane2.sh` with `sed "s#cd ~/sysc-compositor#cd ~/<dir>#"`. Prefix
   runs with `CGO_CFLAGS_ALLOW=-fno-strict-overflow`.
3. Split `internal/wlr` in two halves from `go test -list .` and run each with
   `-run "^(a|b|…)$"`. Run `internal/server` and the lane-1 packages whole. A targeted run can
   pass a race that a batch run catches: run the batches.
4. `./vssh sudo systemctl poweroff`, delete the copied archive.
