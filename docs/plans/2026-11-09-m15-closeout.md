## Audit at the start

`internal/ipc/names.go` lists 141 actions. Nine have no server dispatch:
`DoScreenTransition`, `CenterWindow`, `SetWindowWidth`, `SwitchPresetWindowWidth`,
`SwitchPresetWindowWidthBack`, `ToggleDebugTint`, `DebugToggleOpaqueRegions`,
`DebugToggleDamage`, `ToggleWindowRuleOpacity`. Their wire fields also need review:
the generic decoder currently discards fields for actions it does not handle.
`PickWindow` and `PickColor` requests parse but do not run. The CLI has only 14
action parsers. Existing border, tab and rule-opacity configuration applies.

Sizing is more than wiring: floating focus must not resize an old tiled column;
foreign maximize needs idempotent restore semantics; screenshot sizing uses
physical pixels, including a one-pixel selection at fractional or integer scale.
The existing overview omits background/bottom layer projection and continuous
vertical gesture following. Easing, slowdown and custom shaders still warn.
Config failure notification and debug settings lack implementations.

```sh

  go test -count=1 ./internal/layout -run '^TestWindowWidthAndCenterFollowNiri$'
```

Use that template for config, animation, bind, ipc, cli and wm checks. Compositor
checks run in the pre-approved laptop VM using the handover's lane-2 recipe,
with named tests and no desktop window. Red/green results belong in the execution
record. Fresh `gofmt -l internal/`, `git diff --check`, vet and build precede claims.
