## 5. Proving compositor tests

Nested tests need the owner's consent on the desktop; use the laptop session VM, which matches
CI's lane 2 and is pre-approved. The 2026-11-08 handover §5 recipe still applies, with two
changes that saved time this round:

- To test an uncommitted tree, tar `git ls-files -co --exclude-standard` (minus
  `.commandcode/`) instead of `git archive`, and untar it over a VM checkout that already ran
  `go generate ./internal/wlr`.
- Put `CGO_CFLAGS_ALLOW=-fno-strict-overflow` in the lane-2 script's `export` line rather than
  on each command (`~/lane2-m15-closeout2.sh` in the VM is an example).

`internal/wlr` must run in two halves: the whole package's test binary passes 4.4 GB and the
VM's OOM killer stops it, on `main` too. Expected: 335 pass, 4 skip (nested host, render node,
ibus). Tests that read `/home/nomadx/references` (the Niri default config, `TestNamesMatchNiri`)
skip in the VM; run them locally by name.

## 6. Workspace notes

- The untracked `.commandcode/` stays untracked; never `git add -A`.
- A pixel test that needs what reached the display, not what a capture renders, can use
  `probeOutputFrames`.
- An idle `testclient.ToplevelClient` never acks a configure unless told: with resize
  throttling and transactions, call `AcknowledgeConfigure` on every client before asserting a
  configured size, and allow until the 300 ms transaction deadline.
- `/home/nomadx/sysc-shell` (primary checkout) may hold another session's work; use a worktree.
  `bd` reads from it safely.
- The global commit-msg hook rejects AI attribution lines and the substrings "both", "agent",
  "cursor" and "bot" (even inside words such as "bottom"); commit without them.
- Merging: the owner approves merging what reviews clean, without waiting for CI. Force-pushes,
  rebases of PR branches, deploys that log the owner out, greeter changes and packaging
  submissions remain owner acts.
