## Working rules (unchanged, all binding)

- One package, explicit test names, `timeout 90s env GOMAXPROCS=2 go test -count=1 <pkg> -run '^(…)$'`.
  Never `go test ./...`, never `-race`.
- A test compositor opens a window on the owner's desktop. Nested tests run only
  with the owner's per-run consent on the desktop; the laptop VM and laptop gates
  are pre-approved. Never in a loop, script or background job on the desktop.
- `runtime.LockOSThread()` before wlroots calls; Go + cgo only, no `.c`/`.h`.
- `go generate ./internal/wlr` once per fresh tree (generated headers ignored).
- **No AI attribution anywhere** (commits, PRs) — the owner's iron law. The global
  commit hook also rejects the substrings "both", "bot", "agent", "cursor"
  (including inside words and test names).
- Auto mode refuses direct pushes to `main`, `gh pr merge`, force-push and rebases
  of PR branches: push a branch, open a PR, and let the owner merge.
- Laptop gate builds keep the basename `sysc-compositor` (sysc-lock, `sysc-2261`).
- bd runs from `/home/nomadx/sysc-shell` (no `--json`).
