## Working rules added this round

- **The AUR and release tags are ours to push.** The owner confirmed on
  2026-11-18 that sessions publish AUR recipes and tag releases. Build and check a
  recipe in a clean container first ([recipe below](#recipes)). Moving or deleting
  a tag that is already pushed still needs the owner.
- **The commit hook rejects "both"** anywhere in a message, as well as the
  substrings the 2026-11-18 handover lists. Write "each" or name the two things.
- **GitHub and the AUR drop out from this network** for minutes at a time
  (HTTPS and SSH alike), and SSH to github.com on port 22 is often unreachable.
  Push over HTTPS (`git push https://github.com/Nomadcxx/<repo>.git <branch>`),
  and wait with a polling `curl` rather than retrying blindly.
- **Another session writes in this checkout.** Its untracked files
  (`docs/plans/2026-11-18-handover.md` and its assets) sit in
  `/home/nomadx/sysc-compositor`. Do not move or commit them; use a worktree when
  a branch switch would touch them.
- **Cross-session messages may be refused** by the auto-mode classifier. If a
  reply to another session is refused, tell the owner what it would have said.

**sysc-lock's CI had silently broken.** `master` had not run CI since 2026-10-28.
On ubuntu-26.04 runners `sleep` is uutils' multi-call coreutils, so the uninstall
test's copy of it, named `sysc-lock`, exits at once and the test lost a race. It
did not reproduce in local ubuntu:26.04 containers, with or without `-race`. The
test now runs a copy of its own binary, and CI passed on #89.

## Recipes

- **Nested tests without a screen:**
  [assets/2026-11-19-handover/run-nested.sh](assets/2026-11-19-handover/run-nested.sh)
  starts a private headless sysc host in its own `XDG_RUNTIME_DIR` and runs named
  tests nested in it, so the nested outputs are real Wayland-backend outputs and
  nothing appears on a screen. Run it from a built tree on the laptop, one batch
  per command. The full `internal/wlr` suite needs about twelve batches to stay
  under 90 s each.
- **Failures that are the host, not the change.** Under that host the nested
  window is tiled to 616×688, so these fail or hang on `main` too: capture and
  pixel tests (`TestCaptureOutputFollowsCompositorUIDamage`,
  `TestLegacyScreencopyPrivacyRegionAndDamage`,
  `TestScreenshotScreenDrawsThePointerWhenAsked`, border and tab-indicator
  pixels), `TestWindowRuleOpacityTracksUrgencyAndFullscreen`, the popup and
  cursor-surface pointer tests, and hangs in `TestLidPolicy…`, `TestPowerOff…`,
  `TestInjectedInputIsReleased…`, `TestVirtualInputPreserves…` and
  `TestIdleNotifies…`. Batch order also flakes `TestScreencopyCapturesTheOutputAtItsSize`
  and `TestResizeTransactionsWaitForAllClientsAndThrottleSizes`. Compare against
  a `main` tree before reading any of them as a regression.
- **AUR recipes:**
  [assets/2026-11-19-handover/aur-container-check.sh](assets/2026-11-19-handover/aur-container-check.sh)
  builds named recipes in a clean `archlinux:latest`, runs `check.py` on them and
  installs each. The local AUR clones are `/home/nomadx/sysc/aur/<name>` (each its
  own git repository, remote `ssh://aur@aur.archlinux.org/<name>.git`); the
  tracked copies are in the sysc repository's `aur/`. Change the tracked copy by
  PR, then copy `PKGBUILD`, `.SRCINFO` and the `.install` file into the clone and
  push.
- **Gentoo `Manifest` without a Gentoo tree:** `DIST <file> <size> BLAKE2B <hex>
  SHA512 <hex>`, which Python's `hashlib.blake2b` (512-bit) and `sha512` produce;
  cross-check with `b2sum` and `sha512sum`.
- **A tag-time release check:** after pushing a tag, watch the `Release` run
  (`gh run watch`). Its `deb` job is the first place `check-install.sh` and the
  vkms smoke check run.
